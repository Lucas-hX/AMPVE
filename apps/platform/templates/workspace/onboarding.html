AMPVE will run instead of your previous software. We keep the original software on the board and save the files needed to return to it. Returning to it requires a guided USB recovery; there is no app-switching button.

Return to original software

Restore the saved original software and settings if AMPVE setup cannot finish. This removes new AMPVE settings. The browser will reconnect through USB TO UART and compare the board before writing. If automatic reconnection fails, use the connection help; do not erase the board.
